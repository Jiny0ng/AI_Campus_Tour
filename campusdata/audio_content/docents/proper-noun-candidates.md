## 11. 1차 용어집에서 제외해도 되는 항목

다음은 고유명사보다는 일반 시설·기능명에 가까우므로 별도의 UI 번역 사전에서 관리하는 것이 적절하다.

- 강의실, 연구실, 실험실, 세미나실, 회의실
- 화장실, 샤워실, 휴게실, 관리실, 사물함
- 열람실, 그룹학습실, 개인학습실, 스터디룸
- 편의점, 카페, 식당, 서점, 미용실, 우체국, 안경점
- 복사, 출력, 스캔, 코팅, 제본, 대출, 예약
- 층·호실 번호와 `1호관`, `2호관` 같은 순번
- 개인 교수 연구실과 담당자 이름

단, 정식 시설명 안에 포함될 때는 전체 명칭 단위로 용어집에 등록한다. 예를 들어 `중앙도서관`은 고유명사이고 `도서관`만 단독으로 사용될 때는 일반명사다.

## 12. 확인이 필요한 중복·표기 문제

- `전북대학교`, `전북대`, `JBNU`의 언어별 사용 조건
- `인터내셔널센터`, `JBNU 인터내셔널센터`, `실크로드센터`의 현재·과거 명칭 구분
- `박물관`과 `자연사박물관` 구분
- `삼성문화회관`, `문화회관 공원`의 연계 표기
- `동아리전용관`, `동아리 전용관` 띄어쓰기 통일
- `오스스퀘어`, `OS Square` 표기 통일
- `AI Space`, `A.I.모의면접실`의 영문 표기 방식 통일
- `학생타운 1·2`는 과거 명칭, `학생타운`은 통합 후 현재 명칭인지 확인
- `제1학생회관`, `학생회관`, `후생관`이 같은 시설인지 별도 시설인지 확인
- `예술대학 미술관·1-6 예지원`처럼 한 행에 두 시설이 결합된 데이터 분리 여부
- `기존 전주실내체육관`의 현재 공식 명칭 확인
- `전대학술문화회관`의 띄어쓰기와 공식 영문명 확인

## 13. 용어집 확정 시 권장 필드

| 필드 | 설명 |
|---|---|
| `termId` | 변경되지 않는 내부 식별자 |
| `category` | 학교, 조직, 건물, 장소, 인물, 행사, 브랜드 등 |
| `ko` | 한국어 기준 명칭 |
| `en` | 공식 영문명 또는 확정 번역 |
| `ja` | 일본어 표기 |
| `zhHans` | 중국어 간체 표기 |
| `pronunciation` | TTS 발음 보정용 표기 |
| `aliases` | 전북대, JBNU 등 검색용 별칭 |
| `status` | draft, reviewed, approved |
| `note` | 과거 명칭, 번역 금지, 음역 등 규칙 |
