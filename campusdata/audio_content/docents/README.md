# 다국어 도슨트 콘텐츠

지원 언어는 한국어 `ko`, 영어 `en`, 일본어 `ja`, 중국어 간체 `zh`이다.

현재 `*.sample.json`은 번역·낭독 검수용 샘플이며 운영 생성 대상이 아니다. 검수 후 동일 구조의 운영 파일로 승격한다.

## 공통 규칙

- 모든 언어는 동일한 `entityId`와 `contentVersion`을 사용한다.
- `sourceFactIds`는 언어별로 동일해야 한다.
- 목표 낭독 시간은 50~60초다.
- 실제 TTS 생성 시 언어별 낭독 속도를 조정하고, 실청 결과가 50~60초 범위를 벗어나면 대본 또는 TTS 프롬프트를 수정한다.
- 고유명사 표기는 별도 용어집 확정 후 일괄 반영한다.
- `reviewStatus`가 `approved`인 콘텐츠만 TTS 생성 대상으로 사용한다.
- 앱 언어는 `ko`, `en`, `ja`, `zh`를 사용하고 TTS locale은 각각 `ko-KR`, `en-US`, `ja-JP`, `cmn-CN`으로 매핑한다.

## 버전 규칙

`contentVersion`은 화면 텍스트와 음성이 같은 원문에서 만들어졌는지 확인하기 위한 콘텐츠 묶음 버전이다. 샘플에서는 `v1`을 사용한다.

- 맞춤법처럼 발음과 의미가 바뀌지 않는 수정: 버전 유지 가능
- 번역, 사실, 표현 또는 발음이 바뀌는 수정: 해당 장소의 모든 언어 검토 후 버전 증가
- TTS 화자·모델·프롬프트만 변경: `contentVersion`은 유지하고 음성 해시에 포함된 별도 설정 버전 변경

버전이 없더라도 현재 content hash가 캐시 충돌을 막지만, 버전은 운영자가 텍스트·음성 배포 상태를 확인하고 이전 음성으로 되돌리는 데 사용한다.

## 샘플 검수 항목

1. 사실이 원문과 일치하는지
2. 고유명사 표기가 용어집과 일치하는지
3. 해당 언어 사용자에게 자연스러운지
4. TTS 실청 시간이 50~60초인지
5. 화면 텍스트와 음성의 `contentVersion`이 같은지
